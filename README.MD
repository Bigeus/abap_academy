# 💻 Academia ABAP – Códigos de Vinicius Simões

Este repositório contém códigos desenvolvidos durante minha **formação em ABAP** ao longo do programa de **trainee**.  
Os arquivos aqui armazenados estão no formato `.abap` e foram criados em um **ambiente SAP educacional**, sendo executáveis apenas nesse contexto.

<!-- --- -->

## 📂 Estrutura do Repositório

Cada arquivo representa um exercício, desafio ou exemplo de prática realizada durante a academia ABAP.  
Os objetos podem ser facilmente reconhecidos pelo prefixo: ZTT0


Esse prefixo identifica o ambiente e o escopo dos exercícios, comum entre os participantes da academia.

## ⚙️ Observações Técnicas

- Os códigos foram escritos em **ABAP (Advanced Business Application Programming)**.  
- Alguns exemplos utilizam **tabelas e estruturas personalizadas** criadas apenas no ambiente de treinamento.  
- A execução completa pode **não funcionar em sistemas SAP externos**, por depender desses objetos locais.  
- O repositório tem fins **educacionais e de portfólio**, para registrar minha evolução técnica durante o programa.

## 📘 Sobre o Propósito

Este repositório serve como registro do meu aprendizado em:
- Estruturas de dados ABAP (tipos, tabelas internas, estruturas);
- Modularização (FORMs, FUNCTIONs, includes);
- Manipulação de banco de dados (Open SQL);
- Criação de relatórios e telas simples (SE38 / ALV);
- Boas práticas e padrões utilizados em sistemas SAP corporativos.
